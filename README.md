# Calculator Master

Simple menu-driven calculator built in Python for ITNT415. Uses Git branching for each operation, merged into main through pull requests.

## Student Info
- Name: Liam Syengtay
- Course/Section: ITNT415 - BIT42

## About
Command-line calculator with add, subtract, multiply, and divide. Each operation was built on its own branch and merged into main once done.

## Branches
- main - skeleton + final merged version
- addition_Syengtay
- subtraction_Syengtay
- multiplication_Syengtay
- division_Syengtay

Each branch has at least 2 commits and was merged via a pull request.

## Features
- Menu loops until you choose to exit
- Checks for valid menu input
- Checks for valid number input (no crashing on bad input)
- Handles divide by zero
- Separate function for each operation
